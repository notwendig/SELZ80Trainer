# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue.

Use GitHub's private vulnerability reporting / Security Advisory mechanism for this
repository when available. Include:

- affected commit/version;
- reproduction steps;
- expected and actual behavior;
- impact;
- any proposed fix.

For ordinary crashes, build failures and emulator correctness problems that do not
have a security impact, use the normal issue tracker.

## Scope

Security reports should concern the SELZ80Trainer application or repository
infrastructure. Vulnerabilities in the `Z80` or `qvintage` submodules should also be
reported to their respective upstream repositories when the problem originates there.
