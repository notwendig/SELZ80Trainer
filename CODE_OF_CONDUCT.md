# Code of Conduct

SELZ80Trainer contributors are expected to keep project communication technical,
respectful and constructive.

## Expected behavior

- Discuss code, behavior and evidence rather than attacking people.
- Give reproducible technical feedback where possible.
- Accept that maintainers may request narrower changes or additional testing.
- Respect authorship, licenses and third-party rights.
- Keep issue and review discussions relevant to the project.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, deliberate disruption, publication of
private information, or repeated bad-faith behavior is not acceptable.

Project maintainers may edit, hide, lock or remove contributions that violate these
rules and may restrict participation when necessary to protect the project and its
contributors.

Security issues should follow [SECURITY.md](SECURITY.md).
